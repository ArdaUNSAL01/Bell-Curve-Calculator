# 📊 Bell Curve and Z-Score Calculator

This project is a command-line interface (CLI) Python tool that calculates the bell curve distribution of class grades and determines a student's **Z-Score**. 

It analyzes raw grade inputs from the user to calculate the class mean, standard deviation, and the target grade's position on the bell curve.

## 🎯 Project Objectives (Learning Goals)
While developing this software, my primary focus—alongside building a working application—was to **practice and improve my skills** in the following technical concepts:
- **Object-Oriented Programming (OOP):** Designing the code modularly using classes and methods.
- **NumPy Library:** Utilizing `numpy.array` to perform statistical operations (`mean`, `std`) efficiently.
- **Exception Handling:** Using `try-except` blocks to catch invalid or unexpected user inputs and prevent the program from crashing.

## 🚀 How It Works
1. Upon execution, the program prompts the user to enter the class grades one by one.
2. Once the grade entry is finished (by typing 'E'), the system asks for the student's target grade.
3. The class mean and standard deviation are calculated in the background using `NumPy`.
4. The Z-Score formula is applied, and the user's status on the bell curve (Pass/Fail) is displayed on the screen.

## 🛠️ Technologies Used
- Python 3.x
- NumPy (Data manipulation and mathematical calculations)
- OOP (Object-Oriented Programming Architecture)
